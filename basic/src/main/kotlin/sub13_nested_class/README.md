### Java 중첩 클래스
- 중첩 클래스 종류
  - static 을 사용하는 중첩 클래스
    - 외부 클래스를 직접 참조 불가함.
  - static 을 사용하지 않는 중첩 클래스
    - inner class(내부 클래스)
      - 외부 클래스를 직접 참조 가능
    - local class
      - 메서드 내부에 클래스를 정의.. 사례가 거의 없음
    - anonymous class
      - 이름이 없는 일회성.. 익명 클래스
- 여기서 일반적으로 중첩 클래스란.. static 을 사용하는 중첩 클래스와 inner class(내부 클래스) 를 지칭한다.

  - item 86
    - 내부 클래스를 직렬화를 할때.. 내부클래스가 외부클래스를 참조하고 있기 때문에 내부 클래스의 직렬화 형태가 명확하게 정의되지 않아 직렬화에 있어 한계가 있다.
  - 그래서.. 클래스 안에 클래스를 만들때는 static 을 사용하는 중첩 클래스로 만들라는.. 말이 생김
